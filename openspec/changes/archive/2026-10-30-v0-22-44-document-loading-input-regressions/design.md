## Context

最新本人指示はトークン復旧を先行し、認証確認後に報告済み不具合全件を修正すること。HomebrewはActions run 40936028271で本人/対象repoのGET200を確認。WinGetは本人登録したローカル値で本人/対象fork/public_repoを確認した。GET成功と公開書込の成功は区別する。

## Goals / Non-Goals

- 画像単独でなく、Office/HTMLの処理が未完了の間の画像選択・表示・終了を守る。
- 共通部品とcallerの実配置・入力所有を自動検査する。
- 本人実機確認をClose条件にしない。本人アプリ/設定を勝手に変更しない。
- 既存の必須ゲートを下げず、Draft中は指摘修正に集中する。

## Decisions

- 原因未確定のメモリ/バッファ不足やキー競合を確定事実として扱わない。旧高速harness結果で本人報告を否定しない。
- 本体のblocking/待ち行列/再読込と、上流レンダリングの遅延を切り分ける。上流コードは編集せず既存Issueへ証拠を渡す。
- ローディング配置は共有部品で保証する。bounded/inline/fullscreenの意味を維持し、無限高のScrollAreaへ無制限領域を確保しない。
- キー操作は文書活性化とフォーカスの契約を明示し、検索/エディタ/modal/修飾キー/タブ操作を奪わず、同じキーを二重処理しない。
- 関心事別通常commit/push、Draftレビュー/修正/reply/resolve、Ready後必須CI、merge/公開/後処理を元条件で行う。

## Risks / Trade-offs

実UIの遅延が単体harnessで再現しない可能性がある。該当経路の原本/混在負荷/実描画の観測を保存し、未再現を完了扱いしない。重いCargoとRSS測定を同時実行しない。
